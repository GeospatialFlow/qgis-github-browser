[general]
name=GitHub Browser
qgisMinimumVersion=3.28
description=Browse, open, edit and upload files in GitHub repositories from within QGIS
about=A dockable panel that lets you browse GitHub repositories (including private ones, using a personal access token) as a tree, open Python files in the QGIS Python Console editor, upload edited tabs back as commits, search file names across a repository, and view a file's commit history with colored diffs. Also includes a Processing algorithm to download a single file from a repository. Uses only the GitHub REST API - no git installation required. Security: the token is kept in memory only by default (optionally remembered encrypted in the QGIS authentication database), is sent only to api.github.com over verified HTTPS, and downloaded code is never executed.
